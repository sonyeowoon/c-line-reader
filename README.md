# C Line Reader

파일 디스크립터에서 데이터를 나누어 읽고 한 번 호출할 때 한 줄을 반환하는 C 입출력 학습 프로젝트입니다. 읽은 데이터에서 줄바꿈을 찾고 남은 문자열을 다음 호출까지 보관합니다.

## 주요 구현

- `read`를 이용한 고정 크기 버퍼 입력
- 줄바꿈 위치 탐색과 문자열 결합
- 정적 변수에 남은 데이터를 보관하는 상태 유지
- 파일 끝과 읽기 오류 처리
- 동적 문자열 메모리 관리

## API

```c
char *get_next_line(int fd);
```

반환된 줄은 사용한 뒤 호출자가 `free`해야 합니다. 줄바꿈이 있으면 반환 문자열에 포함됩니다. 더 읽을 줄이 없거나 오류가 발생하면 `NULL`을 반환합니다. 함수·소스 파일 이름은 호환성을 위해 기존 이름을 유지합니다.

## 빌드 예시

독립 실행 프로그램이나 Makefile은 포함되어 있지 않습니다. 호출 코드를 작성한 후 두 소스 파일과 함께 컴파일합니다.

```sh
cc -Wall -Wextra -Werror -D BUFFER_SIZE=64 main.c get_next_line.c get_next_line_utils.c -o line-reader
```

`main.c`는 사용자가 준비하는 호출 프로그램입니다. `BUFFER_SIZE`를 지정하지 않으면 헤더의 기본값 2를 사용합니다.

## 구성과 제약

- `get_next_line.c`: 줄 추출과 잔여 데이터 관리
- `get_next_line_utils.c`: 문자열 및 메모리 보조 함수
- `get_next_line.h`: 함수 선언과 버퍼 크기 설정

잔여 데이터를 단일 정적 변수에 보관하므로 여러 파일 디스크립터를 번갈아 읽는 용도로 사용하면 안 됩니다. 스레드 안전성을 제공하는 구현이 아닙니다. 빈 파일·마지막 줄바꿈 유무·버퍼 경계·읽기 오류에 대한 실행 검증은 별도입니다.
